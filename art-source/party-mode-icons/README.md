# Party mode button illustrations

Generated with built-in imagegen. Each PNG's matching JSON records its full prompt,
reference role and original generated-file path. Runtime images are full-resolution,
lossless transparent WebP conversions:

- `icons/mode-team-worlds.webp`: spaceship in flight, angled up and right, with engine flames.
- `icons/mode-high-low.webp`: mostly shark head, facing right with open jaws.

Used by Party hub buttons and matching destination headers. Solo Worlds and Solo
Survival retain their existing illustrations.
