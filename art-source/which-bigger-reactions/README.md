# Which Is Bigger summary reactions

Generated with the built-in imagegen tool using the existing elephant and mouse mascots as character/style references. Each PNG has true transparency. Per-image JSON files preserve the prompts and original generated paths.

The happy elephant has actual closed-eye artwork, with its complete trunk in a separate layer. The upset mouse has a separate complete foot/shin. The animated joints overlap their body layers; moving parts contain no scenery or pieces of neighboring characters. Full source PNGs remain here, and the four runtime WebP layers are in `anim/which-bigger-art/`.

`scripts/register-which-bigger-art.py` performs full-resolution lossless WebP conversion, verifies byte-identical decoded pixels/alpha, and records read-only alpha bounds in `assets.mjs` for aligning transparent margins. No programmatic painting or background removal is used.

Both animals remain to the left of the outcome badge. Correct answers use the happy elephant, a trunk lift and water arc from the moving tip; wrong answers use the upset mouse, a foot stomp, impact ripple and two anger symbols. Reduced motion shows still poses. Leaving the summary removes its motion; inactive screens pause it. Existing scoring, life loss, sounds, streaks and broad size-gap wording are preserved; no measurements are revealed.

The phone-width real-game screenshots and motion checks are generated by `scripts/verify-which-bigger-summary-browser.cjs` under `output/which-bigger-summary/`.
