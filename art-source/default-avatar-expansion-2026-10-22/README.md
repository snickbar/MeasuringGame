# Default avatar expansion and review concepts

The built-in image-generation tool created twelve new transparent avatars, with the existing game avatars as style references. The complete prompt set and original generated paths are in `generation.json`; the raw PNGs are preserved here. The game exports use the generated alpha, crop only empty transparent canvas, and fit the artwork into a 256px transparent square. No existing avatar image is overwritten.

- av314–315: Curly Kai and Bookish Bea (two kids).
- av316–317: Silver Skye and Freckle Frank (two adults).
- av318–319: Grandma Mei and Grandpa Dev (two grandparents).
- av320–322: a platypus, pangolin and Malayan tapir.
- av323–325: a backpack, closed book and artist’s palette.

The full previous avatar roster was checked before choosing subjects: the originally considered otter, rabbit and turtle were rejected because they were already represented. The selected three animal species and three object subjects are new to the avatar roster. People have different combinations of age, hair, facial features and clothing. The first boy’s eyes were revised to match the set’s simple dark oval eyes.

The twelve additions began as Default/free. The user's approved `size-em-up-avatar-tiers (8).json` is archived as `approved-tiers.json` and is now applied: 44 Default and 121 Common, in the exact approved order. Rare and Ultra retain their original tiers and relative order. `previous-tiers.json` captures the pre-expansion registry. The review page (`anim/avatar-tier-review.html`) reflects the applied choices, supports group changes and two-card position/group swaps, and exports a validated JSON file. Rare and Ultra are excluded from both the displayed data and allowed imports. The page does not change the live registry itself.

The user approved all four object revisions in `anim/artwork-candidates-2026-10-22-v3/`. These are exported to the actual `items/` WebP files with transparency, preserving the grey minivan, airliner direction, Notre-Dame tower facade and London Eye identity. Only empty transparent margins were cropped, and exports were resized without redrawing. Prompts are in `generation.json`. Measurements and orientation settings remain unchanged. Original WebP files are preserved as `*-before.webp`, and `anim/artwork-comparison.html` presents previous/applied pairs with zoom and inspection backgrounds.

`anim/mode-identity-mockups.html` preserves the approved concept using the game's actual art and Fredoka font. The implemented `mode-identity.mjs/css` applies mode palettes, subtle artwork motifs, panel accents and gradients to actual mode screens. Team variants share their family. Monthly artwork follows the current pack. Style includes Match game mode, Plain, and seven free individual gradients (including Classic Party's orange). Explicit gradients and owned custom backgrounds override automatic mode and monthly backgrounds. Home keeps its separate home-screen selection, and size-reveal scenery is unchanged. Isolated browser checks cover actual profile persistence, Style equip, mode routes, tile cleanup, background precedence and phone widths 320/390/430.

The implemented discovery feature records first encounters atomically with completed-round receipts. Previously seen objects are not reclassified as new. Both sides count; completed missed and abandoned rounds count, but discovery never finishes/wins a game. Recent objects appear on the existing Objects page, and each finished session can show a compact strip inside its existing result card. Object popups show available appearance counts, without measurements. Profile normalization retains the new metadata. Tests cover transaction retries, older profiles, session scope, actual profile loading/UI, safe swaps and every review image at phone widths.
