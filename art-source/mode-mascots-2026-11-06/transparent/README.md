# Transparent mode mascot PNGs

All 30 selected mascot illustrations have real transparent alpha channels. Original white-background images remain in the parent folder.

Open `index.html` to view every image and switch the preview between checkerboard, light and dark backgrounds. Click any image for its full PNG. The preview backgrounds are not part of the files.

`manifest.json` identifies each image's mode and role. `review/alpha-report.json` records dimensions, transparent and nearly opaque pixel counts, and transparent corner checks. Light/dark review sheets are in `review/`.

The raccoon holds a blank spiral notepad in all poses. White character details such as spacesuits, eyes, robot panels, fur and paper remain visible. These assets are ready for review and integration; they are not active in gameplay yet.
