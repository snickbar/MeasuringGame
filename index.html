How to Play

Creating a room

Tap Create Game, enter your name, pick an avatar, and tap Create room. You're the host - only you can change the room settings and start the game.

Joining a room

Tap Join Game, type the 4-letter room code the host gave you, enter your name, and pick an avatar. Every player needs a unique avatar per room, so any already taken will be grayed out.

Rejoining a room

If you get disconnected or reload mid-game, open Join Game - your most recent room shows up as Last game with a one-tap Rejoin button.

Host settings

Chosen once when you create a room:

If host disconnects - "Give another player host" auto-hands host duties to whoever's been in the room longest if you drop; "Save my host spot" holds your spot so rejoining under the same name gets it back.

Adjustable any time from the lobby (before the game starts):

Timer - how many seconds each round's guessing phase lasts. Rounds - how many rounds the game runs. Second-chance scoring - turns on the pick/double-down phase after guesses lock (see below). Bots use second chances - lets bots join in on that phase too. Item selection - see next section.

Item selection

Anything goes pairs any two objects at random, so you might get wildly mismatched sizes. Keep it relative only pairs objects where the smaller one is at least 15% of the larger one's size, so you won't be asked how many grains of sand long the Eiffel Tower is.

Second chances

When it's on, everyone gets a few seconds after guesses lock to either pick another player's answer (if you think they nailed it) or double down on your own guess. Picking the round's actual closest answer earns you a bonus point; doubling down doubles your own points if your guess turns out to be the closest.

Scoring

Only the single closest guess each round scores: +3 points normally, or +5 if it's within 0.9 of the exact answer. Everyone else gets 0 for that round, no matter how close they were.

Second-chance bonus: +1 for correctly picking the round's closest answer.

Double down: if your own guess is the round's closest, doubling down doubles those points (an extra +3 or +5 on top).

"Spot On!" (within 1% of the answer) and "Perfect!" (within 0.005) are just on-screen recognition, not extra points.

At the very end of the game, the top 3 players by average guess accuracy (how close their guesses ran to exactly 100% of the real answer, on average) get a one-time bonus: +10 / +6 / +3.

Tiebreakers

During the game, tied scores just stay tied - same medal, no resolution needed. In the final results, a tied score is broken by whoever's average guess accuracy is closer to 100%; if that's tied too, they stay tied there as well.

Good to know

Bots can be added from the lobby (Easy/Medium/Hard) if you want to practice solo or fill out a small group. Reactions let you send an emoji while waiting for everyone else to guess. The host can Pause to freeze the timer, and either the host or a player can Exit at any time.
